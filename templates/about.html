Project Overview

The Speech Emotion Recognition (SER) System is designed to analyze speech patterns and detect emotional states for early depression risk monitoring. It combines machine learning, audio processing, and user interaction to provide meaningful insights into mental health.

Accessibility Commitment

This system is built with accessibility in mind. Blind and visually impaired users can navigate using screen readers, keyboard shortcuts, and descriptive labels. Charts and visualizations include text summaries for clarity.

Features

  • Speech emotion detection with confidence scores
  • Depression risk analysis and instability index
  • Interactive dashboard with history tracking
  • PDF report generation for professional use
  • Accessible design with ARIA roles and alt text
