# Speech Emotion Recognition for Depression Detection

## Technologies
- Python
- TensorFlow / Keras
- CNN + BiLSTM
- Flask
- HTML, CSS, JavaScript
- SQLite

## Features
- Upload speech audio (WAV)
- Emotion detection
- Depression risk estimation
- Interactive dashboard
- Emotion history storage

## How to Run
1. Install requirements
   pip install -r requirements.txt

2. Train model
   python model/train_model.py

3. Run web app
   cd backend
   python app.py

4. Open browser
   http://127.0.0.1:5000

## Dataset
- RAVDESS Speech Dataset
